The Intersection of Atoms & Bits

I am an independent aerospace software engineer, hardware hacker, and full-stack system architect based in Dhaka, Bangladesh. I specialize in building autonomous drone navigation platforms, agentic AI systems, and mission-critical web ecosystems from scratch.

"Hardware without intelligent software is just a silent sculpture. Software without physical actuators is merely an abstract simulation. True magic ignites at the low-latency boundary where code commands physical flight."

Rather than treating software and hardware as separate realms, I bridge physical mechanics with distributed intelligence—from custom flight controllers and low-latency motor telemetry to neural network inference on edge microprocessors.
